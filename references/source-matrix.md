# Portable source matrix

These are source classes, not installed integrations. Every adapter must be
explicitly configured and authorized. Credentials never belong in this file.

| Class | Meaning | Public edition |
| --- | --- | --- |
| H1 | Work item, relationships and change history | Fictional fixture plus adapter contract. |
| H2 | Relevant correspondence | Contract only. |
| H3 | Feature discussion and scoped approval | Fictional approval; contract for actual discussions. |
| H4 | Consented transcript | Local VTT parser; fetching not bundled. |
| H5 | Product specification | Fictional source and extracted claims. |
| H6 | Engineering reference | Contract only. |
| H7 | Deployment observations | Generic normalized-row summarizer; no backend queries. |
| H8 | Documentation and graph evidence | Reconciliation/ownership modules and fictional candidates. |
| H9 | Public API/reference material | Contract only. |
| H10 | Prior feature decisions | Local feature-notes store. |

Record which classes were reached and why others were unavailable. Do not
equate “adapter implemented,” “account authorized,” “query succeeded,” and
“evidence supports this claim.” They answer different questions.
