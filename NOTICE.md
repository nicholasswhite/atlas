# Provenance and attribution

Nicholas White designed and developed Atlas with AI coding assistance. The
original project addressed a professional release-documentation workflow. This
standalone edition was prepared for public inspection with fictional inputs,
portable configuration, and a new repository history.

## Retained and adapted

The dossier, relationship analysis, lifecycle resolution, tag transformation,
documentation-impact reconciliation, ownership planning, feature notes,
assignment log, handoff queue, timeline planner, transcript parser, and identifier
resolver were adapted from that original implementation. Tests preserve relevant
behavior while replacing original names, work records, paths, and product examples.
Legacy field names such as `ado_id`, `crw`, `ms.author`, `iddraft`, and `wnready`
remain documented compatibility conventions; they do not connect to an account.

## Independently prepared for this edition

The Aurora Sync example, offline template drafting, HTML walkthrough, generic
telemetry observation adapter, public documentation, and release checks were
prepared for this edition with AI assistance. The public external-content
wrapper uses Python's standard XML serializer.

The earlier private design drew on **Scout**, formerly Clawpilot
(`https://github.com/gim-home/m`), for untrusted-input boundaries and task
coordination ideas. Its source-code boundary-escaping port and runtime are not
included here. This attribution does not assert an upstream license or endorsement.

## Excluded

Organization-specific query builders, transcript-fetch integrations, source
archives, actual release dossiers, staff rosters, telemetry identifiers,
work-item records, private endpoints, local machine paths, and original Git
history are excluded. Adapter contracts describe the information needed without
claiming access to any real environment.
